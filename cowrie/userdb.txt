# Which logins the fake server accepts. Syntax: login:x:password, first match wins,
# `*` = anything, /regex/ (add `i` for case-insensitive); no rule matched = refused.
#
# Accepting any password for root is the classic honeypot tell: real servers refuse
# almost everything. Here only the usual weak passwords of mass scanners get in, for
# the usual default accounts. To go back to "accept everything", append `*:x:*`.
